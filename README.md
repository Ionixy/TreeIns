# GoalTree · Дерево целей

Офлайн-приложение для целей: каждая цель — дерево, задачи — его ветки. Всё приложение
(разметка, стили, логика) лежит в одном файле `TreeIns.html`. Ни сборки, ни пакетного
менеджера, ни бэкенда — открыл файл и работаешь.

**Сайт:** https://ionixy.github.io/TreeIns/
**Установка:** https://ionixy.github.io/TreeIns/install.html

---

## Установка

Открывайте [страницу установки](https://ionixy.github.io/TreeIns/install.html) — она сама
определит систему и покажет нужные шаги. Ниже то же самое вручную.

### Android — один файл

1. Скачайте `goaltree.apk` из [последнего релиза](https://github.com/Ionixy/TreeIns/releases/latest).
2. Откройте скачанный файл.
3. **Первый раз** Android попросит разрешить «Установка неизвестных приложений» для вашего
   браузера. Это системное требование Android 8+, обойти его нельзя — разрешите и
   вернитесь к установке. Дальше приложение ставится обычным тапом.

Приложению не нужен интернет: у него нет даже разрешения `INTERNET`. Всё работает сразу
после установки, в том числе в авиарежиме.

### iPhone / iPad — через Safari

Установить iOS-приложение одним файлом нельзя без платного аккаунта Apple Developer, но
Safari умеет ставить веб-приложение на домашний экран — получается тот же значок, запуск
без адресной строки и работа офлайн.

1. Откройте https://ionixy.github.io/TreeIns/ **именно в Safari** (не в Chrome и не внутри
   другого приложения — там пункта меню не будет).
2. «Поделиться» (квадрат со стрелкой вверх) → **«На экран „Домой“»** → «Добавить».

### Компьютер

Просто откройте https://ionixy.github.io/TreeIns/. Chrome и Edge предложат установить
приложение отдельным окном — значок установки появится в адресной строке.

## ⚠️ Данные

Все цели хранятся в `localStorage` браузера под ключом `goaltree:data:v2` (константа `KEY`
в `TreeIns.html`). Ни на какой сервер ничего не уходит — бэкенда нет.

### Две установки — два независимых хранилища

`localStorage` привязан к origin (адресу, с которого открыто приложение). У версии с сайта
это `https://ionixy.github.io`, у APK — свой внутренний адрес. **Это два разных хранилища.**

> Цели, созданные в APK, не появятся в версии с сайта, и наоборот. Синхронизации между
> ними нет и не планируется. Выберите один способ установки и пользуйтесь только им.

Это же означает, что удаление приложения стирает все цели: копии в облаке не существует.

### ⚠️ Keystore: потеряете ключ — потеряете возможность обновлять

APK подписывается ключом из `goaltree-release.jks`. Android разрешает обновить
установленное приложение только APK, подписанным **тем же** ключом.

> Потеря keystore означает, что обновить установленное приложение будет невозможно.
> Единственный выход — удалить старое и поставить новое, **а это сотрёт все цели
> пользователя**. Храните `.jks` и пароли к нему в надёжном месте вне репозитория
> (менеджер паролей, резервная копия). В git они не попадают — см. `.gitignore`.

По той же причине нельзя менять `applicationId` (`com.ionixy.treeins`): для Android это
станет другим приложением, и данные старого будут недоступны.

## Обновление

### Сайт (GitHub Pages)

Запушить в `master` — Pages подхватит сам. Если менялся список файлов верхнего уровня,
добавьте новый файл в массив `ASSETS` в `sw.js` **и обязательно увеличьте `CACHE_NAME`**,
иначе у тех, кто уже открывал приложение, останется старый кэш.

### APK

1. В `android/app/build.gradle` увеличьте `versionCode` (строго больше предыдущего, иначе
   Android откажется ставить обновление) и `versionName`.
2. Пересоберите release-APK (см. ниже).
3. Создайте новый [Release](https://github.com/Ionixy/TreeIns/releases) и приложите файл
   **под именем `goaltree.apk`** — на это имя завязана постоянная ссылка
   `/releases/latest/download/goaltree.apk` со страницы установки.

Обновление поверх старой версии сохраняет цели: `applicationId` и внутренний origin не
меняются. Service worker внутри APK намеренно не регистрируется, поэтому после обновления
показывается новый интерфейс, а не закэшированный старый.

## Разработка

Приложение по-прежнему **не требует никакой сборки**. Достаточно открыть `TreeIns.html`
в браузере. Для проверки service worker и манифеста нужен http (по `file://` регистрация
SW намеренно пропускается):

```bash
python -m http.server 8934
```

Дальше http://localhost:8934/TreeIns.html

Файлы приложения: `TreeIns.html` (всё приложение), `index.html` (точка входа, редирект),
`install.html` (страница установки), `manifest.json`, `sw.js`, иконки.
`TreeIns-artifact.html` — устаревший снапшот, ни с чем не связан.

## Сборка APK

Gradle нужен **только** для APK. Само приложение он не собирает и не трогает — просто
копирует готовые файлы в `assets/` (задача `copyWebApp`), поэтому единственная копия
`TreeIns.html` остаётся в корне репозитория.

### Что нужно установить

- JDK 17
- Android SDK (проще всего — Android Studio, оно поставит SDK и Gradle само)

### Первая сборка

```bash
cd android
gradle wrapper
```

(нужно один раз, чтобы появился `gradlew`; если открываете папку `android/` в Android
Studio, она сделает это сама)

### Ключ подписи

Создаётся один раз, потом только хранится:

```bash
keytool -genkeypair -v -keystore goaltree-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias goaltree
```

Затем скопируйте `android/keystore.properties.example` в `android/keystore.properties`
и впишите пути и пароли. Оба файла (`.jks` и `keystore.properties`) в git не попадают.

### Release-сборка

```bash
cd android
./gradlew assembleRelease
```

Готовый файл: `android/app/build/outputs/apk/release/app-release.apk` — его и прикладывайте
к Release под именем `goaltree.apk`.

### Как устроена обёртка

Тонкий WebView вокруг тех же файлов (`android/app/src/main/java/com/ionixy/treeins/MainActivity.java`):

- Страница отдаётся через `WebViewAssetLoader`, а не `file:///android_asset/`. Это
  принципиально: `file://` даёт opaque origin, где `localStorage` либо недоступен, либо
  требует небезопасных флагов. Загрузчик отдаёт файлы по настоящему https-origin
  (`appassets.androidplatform.net`), одинаковому во всех версиях приложения — только
  поэтому обновление сохраняет цели.
- Разрешения `INTERNET` нет: приложению нечего запрашивать из сети.
- Кнопка «Назад» закрывает открытое модальное окно или панель, а если ничего не открыто —
  сворачивает приложение (не закрывает, чтобы возврат не перезагружал страницу).
