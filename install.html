GoalTree

Дерево целей, которое работает без интернета.

📱 Android

Скачайте один файл и установите его — браузер и интернет дальше не нужны.

Скачать APK

При первой установке Android один раз спросит разрешение «Установка неизвестных приложений» для вашего браузера — это системное требование, обойти его нельзя. Разрешите и вернитесь к загрузке.

🍏 iPhone / iPad

Установка одним файлом на iOS невозможна без платного аккаунта разработчика Apple. Зато Safari умеет ставить приложение с сайта — получится тот же значок на экране.

  1. Откройте эту страницу в Safari (не в Chrome и не внутри другого приложения).
  2. Нажмите «Поделиться» — квадрат со стрелкой вверх.
  3. Выберите «На экран „Домой“».
  4. Нажмите «Добавить».
Открыть приложение

💻 Компьютер

Приложение открывается прямо в браузере. Chrome и Edge предложат установить его как отдельное окно — значок установки появится в адресной строке.

Открыть приложение

Чтобы поставить на телефон, откройте эту страницу на нём — инструкция подстроится под систему.

Две установки — два разных хранилища Версия из APK и версия с сайта хранят цели раздельно: браузер привязывает данные к источнику, а он у них разный. Цели, созданные в одной, не появятся в другой. Синхронизации между ними нет — выберите что-то одно и пользуйтесь им.
